# Fastest-Way Greedy Algorithm

Implementação otimizada em **Python** de um algoritmo guloso (*Greedy Algorithm*) projetado para encontrar a solução ótima ou sub-ótima com complexidade temporal reduzida, focando em cenários de tomada de decisão rápida e alocação de recursos.

---

## 🚀 Sobre o Projeto

Este projeto aborda o estudo e a implementação prática de estratégias gulosas, caracterizadas por fazerem escolhas localmente ótimas a cada etapa com o objetivo de alcançar um globalmente ótimo de forma altamente performante:
* **Abordagem Gulosa:** Tomada de decisão imediata baseada no melhor ganho marginal por passo.
* **Otimização de Complexidade:** Foco em alcançar reduções significativas no tempo de execução ($O(n \log n)$ ou $O(n)$) comparado a abordagens de força bruta ou programação dinâmica pesada.
* **Validação de Cenários:** Testes práticos com conjuntos de dados estruturados para verificar a eficácia e os limites teóricos da heurística gulosa escolhida.

---

## 🛠️ Stack Tecnológica

* **Linguagem:** Python
* **Conceitos de Engenharia:** Análise de Complexidade de Algoritmos, Estruturas de Dados Eficientes, Ordenação e Heurísticas de Decisão

---

## 📊 Decisões Técnicas e Desempenho

1. **Estratégia de Ordenação Prévia:** O algoritmo aplica ordenação inicial inteligente dos dados de entrada para assegurar que a escolha gulosa ocorra em tempo linear após o pré-processamento.
2. **Trade-off de Espaço/Tempo:** Otimização do consumo de memória RAM através de estruturas iterativas diretas, evitando recursões profundas desnecessárias.
